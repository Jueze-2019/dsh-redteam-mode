# 红队渗透工具调研：五类智能体的"最常用 / 最有名 TOP3"

> 调研时间：2026-09-20　调研范围：信息收集、资产梳理、漏洞发现、漏洞利用、内网渗透 五类
> 数据来源：GitHub REST API 实测（star / fork / 最后提交时间）、FreeBuf 2025 渗透工具 Top30、Recorded Future、
> PT Security dbugs 开源 C2 综述、C2 Framework Market Landscape 2026、补天×奇安信《中国实战化白帽人才能力图谱（2025）》

---

## 0. 先明确一件事：「最有名」≠「实际使用最多」

调研中反复出现同一个错位，先把结论说在前面：

| 维度 | 谁赢 | 说明 |
| --- | --- | --- |
| 开源知名度（star / 搜索结果） | 大而全的框架 | 如 Sherlock、spiderfoot、OneForAll——学习资料多、教程多，但红队实战未必天天用 |
| 实际使用量 | 小、快、专、稳的单点工具 | 如 fscan、nuclei、ffuf、frp——不出名但每场都跑 |

下面每类的 TOP3 以**实际使用量**为主排序，并单独标注"最有名"的候选，两者不一致时说明原因。
star 数为 2026-09-20 GitHub API 实测值。

## 1. 信息收集（recon）

| 排名 | 工具 | star（实测） | 类型 | 为什么是它 |
| --- | --- | --- | --- | --- |
| 1 | **Amass** (OWASP) | 15,195 | 开源 | 攻击面测绘的"标准件"，DNS 枚举 + 资产发现一体化，字典大、支持被动/主动双模，写报告时的默认出处 |
| 2 | **subfinder** (ProjectDiscovery) | 14,465 | 开源 | 被动子域枚举的事实标准，快、稳、能接 API 源，几乎所有自动化流水线的第一环 |
| 3 | **theHarvester** | 17,561 | 开源 | 邮件/子域/人名 OSINT 收集的老牌工具，Kali 内置 |

**最有名但不是最常用的**：`SpiderFoot`（22,419 star，OSINT 自动化平台，偏威胁情报）、`Sherlock`（92,177 star，用户名跨社交网络追踪——star 全类第一，但属于人物 OSINT，红队打单位资产时基本不用）、`OneForAll`（10,076 star，国内子域收集口碑最好）。

**国内口径补充**：海外团队用 `subfinder + httpx + katana`（ProjectDiscovery 全家桶）；国内团队更多用
**FOFA / Hunter / Quake** 做测绘式信息收集（见第 2 类），再配 `OneForAll`、`EHole(棱洞)` 做指纹。

**与本项目对照**：我们已有的 `passive-recon`（crt.sh/dig/whois）、`fofa-recon`、`web-fingerprint`、
`browser-automation`、`kimi-webbridge` 已覆盖该类的国内主力路径；
缺口是 **subfinder / httpx / katana / dnsx** 这条 ProjectDiscovery 流水线（技能文档里已列出二进制路径，但未成技能）。

## 2. 资产梳理 / 资产测绘（asset mapping）

这一类别要拆成两层，混在一起谈会失真。

### 2.1 互联网空间测绘平台（找"外部有哪些资产"）

| 排名 | 工具 | 类型 | 说明 |
| --- | --- | --- | --- |
| 1 | **FOFA** | 商业（国内） | 国内红队/攻防演练实际使用率第一的测绘引擎，语法强、指纹库贴合国内资产 |
| 2 | **Shodan** | 商业（海外） | 国际最有名的联网设备搜索引擎，FreeBuf Top30 中唯一入选的测绘平台 |
| 3 | **Quake（360 夸克）** | 商业（国内） | 国内三家里协议识别与"服务"维度最强，与 FOFA 常互为补充 |

**并列候选**：`ZoomEye`（知道创宇，国内老牌）、`Censys`（学术/证书维度强）、`Hunter`（奇安信，国内常用）。

### 2.2 资产梳理与攻击面管理平台（把资产"管起来、排优先级"）

| 排名 | 工具 | star（实测） | 类型 | 说明 |
| --- | --- | --- | --- | --- |
| 1 | **Goby** | —（闭源） | 商业/免费 | 国内红队资产梳理 + 漏洞扫描一体化口碑第一，PoC 生态活跃 |
| 2 | **ARL（灯塔）** | —（原仓库已下线） | 开源（国内） | 自动化资产侦察与资产分组，国内资产梳理的经典开源方案 |
| 3 | **nuclei** | 31,326 | 开源 | 以"资产验证 + 模板化检测"承担梳理末端的资产确认；GitHub topic `attack-surface` 第一名 |

**其他高分候选**：`reNgine`（8,849）、`reconFTW`（8,125）、`osmedeus`（6,572）、`NetBox`（21,560，偏 CMDB 而非渗透）、
`Sn1per`（11,256）。国内还有 `ShuiZe(水泽)`（4,022）、`nemo_go`（2,093）。

**与本项目对照**：我们用 SQLite 资产库 + `asset-correlation` 技能做域名↔IP↔C 段↔证书图谱，
`redteam_asset_link` 落 edge 表——**自建方案已覆盖 ARL 的核心价值（资产分组与关联）**，
但没有 Goby 的 PoC 库、也没有 ARL 那样的"资产自动分团队/分项目"能力。这是可选补强点，不是必须。

## 3. 漏洞发现（vulnerability discovery）

| 排名 | 工具 | star（实测） | 类型 | 为什么是它 |
| --- | --- | --- | --- | --- |
| 1 | **Burp Suite** | —（闭源） | 商业 | Web 渗透的行业标准，Proxy + Repeater + Intruder 几乎是人工挖洞的代名词；FreeBuf Top30 第 4 位 |
| 2 | **nuclei** | 31,326 | 开源 | 模板化自动漏洞扫描的事实标准，社区模板数量与更新速度无对手（topic `vulnerability-scanner` 第一） |
| 3 | **sqlmap** | 38,476 | 开源 | 注入类漏洞自动化检测/利用的绝对标准件，star 全类第二 |

**同级高频**：`Xray`（11,749，长亭，国内 Web 扫描口碑极好，⚠️ 最后提交 2024-10，社区版已停滞）、
`AWVS`（商业，国内使用广）、`ffuf`（16,696）/`dirsearch`（14,741）/`feroxbuster`（8,077）/`gobuster`（14,140，目录爆破）、
`WPScan`、`Nikto`、`Nessus`（商业，合规扫描）。

**口径提示**：若把"漏洞发现"限定为**人工挖掘**，TOP3 是 `Burp Suite + Xray + sqlmap`；
若限定为**自动化扫描**，TOP3 是 `nuclei + Xray + AWVS`。

**与本项目对照**：技能库目前靠"FOFA 测绘 + 指纹 + 接口未授权探查 + Nday/1day"，
**缺少 nuclei 这一环**——nuclei 是本类里性价比最高的补强（模板化、可版本化、结果可结构化落库）。

## 4. 漏洞利用（exploitation）

| 排名 | 工具 | star（实测） | 类型 | 为什么是它 |
| --- | --- | --- | --- | --- |
| 1 | **Metasploit Framework** | 39,030 | 开源 | "目前使用最广泛的安全框架之一、拥有最大用户群体"（FreeBuf 2025 原文），模块库最大 |
| 2 | **Cobalt Strike** | —（商业，闭源） | 商业 | 红队 C2 的事实标准；《C2 Framework Market Landscape 2026》：**IR 数据中观测到最多的框架**，检测覆盖广导致高阶操作者转向替代品 |
| 3 | **Sliver** (BishopFox) | 11,860 | 开源 | 开源 C2 里实际使用量第一，被 Unit 42、PT Security 等反复点名；GitHub topic `c2` 第一名 |

**最有力的行为证据**：真实攻击流量里被观测/被通报最多的框架依次是
**Cobalt Strike（破解版在国内尤其泛滥）→ Metasploit → Sliver / Havoc / AdaptixC2 / Brute Ratel**。
`Havoc`（8,510）与 `AdaptixC2` 是 2024 年后上升最快的开源替代品。

**其他常用**：`BeEF`（11,020，浏览器利用）、`mimikatz`（21,853，凭据提取）、
`Impacket`（16,103，Windows 协议工具集）、`NetExec`（5,867）/`CrackMapExec`（9,162）、
`BloodHound`（3,421，AD 攻击路径）、`evilginx2`（15,654，钓鱼反代绕 MFA）。

**与本项目对照**：本项目不依赖通用 exp 框架，走的是"Web 入口 → WebShell → 隧道"的国内攻防演练路线，
与本类 TOP3 的适用场景不同（那三个偏打点后 C2 维持）。**这是有意的差异，不必强行引入 CS/MSF**；
但 `mimikatz / Impacket / NetExec` 这条凭据与协议工具体系在内网阶段值得补。

## 5. 内网渗透（internal / post-exploitation）

| 排名 | 工具 | star（实测） | 类型 | 为什么是它 |
| --- | --- | --- | --- | --- |
| 1 | **fscan** | 14,578 | 开源（国内） | 国内内网渗透使用率第一的"打点神器"：存活/端口/服务/28 类弱口令/未授权/高危漏洞一次跑完，最后提交 2026-09，仍在活跃维护 |
| 2 | **frp** | 109,522 | 开源 | star 全类第一（也是本次调研全部候选中第一），内网穿透/隧道的事实标准，反向代理、多协议、稳定 |
| 3 | **Godzilla（哥斯拉）** | 4,460 | 开源（国内） | WebShell 管理与内网操作的头部工具，加密马 + 插件生态；与 **Behinder（冰蝎，6,196）** 并列国内红队标配 |

**为什么 Godzilla / Behinder 进 TOP3**：国内攻防演练的"入口交付物"就是加密马——它们的使用量不体现在 star 上，
而体现在**每一个被打下的 Web 站点**上。`AntSword（蚁剑）`（4,717，最后提交 2026-04）是第三选择。

**其他常用**：`gogo`（2,138，链式反应出品，大网段低噪声测绘 + 指纹 + 关键信息提取，专业内网团队口碑极高，
star 数低是因为圈子小不是不好用）、`ligolo-ng`（5,005，TUN 接口隐蔽隧道）、`suo5`（2,812，HTTP/WebShell 隧道）、
`nps`（34,226，⚠️ 最后提交 2024-05，已停滞）、`ysoserial`（9,064，Java 反序列化）、
`mimikatz`/`Impacket`/`NetExec`（横移与凭据）、`Ladon`（5,327，国内大内网扫描器）。

**与本项目对照**：我们已有的 `fscan-intranet` + `gogo-intranet` + `suo5-tunnel` + `webshell-toolkit`（冰蝎/哥斯拉/蚁剑）
+ `vps-reverse-shell`（自建 VPS 落地）**与国内实际最常用组合高度一致**，是本项目最扎实的一块。
唯一明显缺口是 **`frp`**（隧道基建，我们有 VPS 但没有 frp 技能文档）。

## 6. 一页速查

| 类别 | TOP1 | TOP2 | TOP3 | 本项目状态 |
| --- | --- | --- | --- | --- |
| 信息收集 | Amass | subfinder | theHarvester | 🟡 有 FOFA/crt.sh/指纹，缺 PD 流水线 |
| 资产梳理 | FOFA（测绘）/ Goby（梳理） | Shodan / ARL | Quake / nuclei | 🟢 自建资产库 + 图谱已覆盖核心 |
| 漏洞发现 | Burp Suite | nuclei | sqlmap | 🔴 **缺 nuclei**，无 Burp 类代理工具 |
| 漏洞利用 | Metasploit | Cobalt Strike | Sliver | ⚪ 路线不同（走 Web 入口，非 C2） |
| 内网渗透 | fscan | frp | Godzilla / Behinder | 🟢 覆盖最好，缺 frp 技能 |

**建议的补强优先级**：
1. **nuclei 技能**（漏洞发现自动化，模板可版本化、结果可落库）——投入最小、收益最大；
2. **frp 技能**（隧道基建，补齐内网持久通道的第二选择）；
3. **ProjectDiscovery 流水线技能**（subfinder → dnsx → httpx → katana，把外部信息收集标准化）；
4. `Impacket / NetExec / mimikatz` 内网凭据与横移工具技能（补齐内网阶段的协议工具体系）。

**不必补的**：通用 C2 框架（CS/MSF/Sliver）——本项目走"WebShell + suo5 隧道"的国内演练路线，
引入 C2 与现有得分模型（账号/隧道/资产/漏洞）不匹配，且噪声与免杀成本高。
