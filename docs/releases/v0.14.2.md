# v0.14.2 — 桌面端「全面浏览」修复

> 修复 DeepSeek Harness macOS / Windows 桌面客户端无法使用「全面浏览」的问题。

## 更新内容

- 桌面客户端不再依赖会被 Electron 拦截的 `window.open`，改为在当前窗口进入全屏控制台；
- Web 浏览器仍优先打开新窗口；弹窗被拦截时自动回退到当前窗口；
- 面板头部与侧栏底部两个「全面浏览」入口都使用同一套逻辑；
- 保留 v0.14.1 的桌面标题栏避让，全屏视图不覆盖系统窗口按钮；
- 退出全屏按钮和 Esc 均可返回，退出后清除 `#redteam-full` 标记；
- 其余功能与 v0.14.1 相同。

## 升级

```sh
dsh plugin --profile web add dsh-redteam-mode@0.14.2
# 或
dsh plugin --profile web update dsh-redteam-mode
```

装完重启一次 `dsh web`。已有靶局的事实库、得分记录、报告、POC 知识库与攻击文件保持不变。
