# v0.14.0 — 作战态势、控制台精简与 DeepSeek 公开情报

> 本版围绕红队操作体验：把“看数据”变成“看态势”，减少控制台首屏噪音；
> 同时修复新版 DSH 下的红队模式兼容问题，并新增 DeepSeek 官方 Search / Fetch 公开情报技能。

## 更新内容

### 1. 红队模式兼容性修复

- 修复新版 DSH 下红队模式无法启动、执行角色预设无法挂载的问题；
- 子智能体派发恢复正常，主会话与五个执行角色均可使用。

### 2. 控制台

- 新增**态势页**：累计得分、五阶段推进、当前得分/下一步得分、入口、缺口与编队；
- 一级分区收敛为 **态势 / 资产 / 成果 / 报告 / 资源**；
- 资产测绘默认「下一步 10 台」，完整列表和高级筛选降到第二层；
- 漏洞战果只保留漏洞，凭据/访问会话/攻击文件移到资源分区的「凭据与文件」；
- 得分目标默认只列已得分项目，可切换高分缺口/完整列表；
- 报告阶段默认折叠成一行，「四段式全文」改为「详细报告查看」；
- 报告下载文件名使用靶标中文名；页面与下载内容同源，补齐动作/请求/凭据/隧道/攻击文件路径，并修复误报的复现缺口；
- 会话隧道口令默认掩码，长备注/检测说明默认折叠；
- 技能库改为紧凑行，知识库搜索置顶并默认按当前靶标筛选；
- 深色模式下选中按钮的对比度修复，避免白底白字。

### 3. DeepSeek 公开情报技能

新增 `deepseek-web-intel`（随包技能，当前 16 个随包 / 25 个总技能）：

- **Search**：`POST https://api.deepseek.com/v1/tools/search`；
- **Fetch**：`POST https://api.deepseek.com/v1/tools/fetch`；
- 零依赖客户端，单线程、限速、退避重试，结果落盘 `runs/deepseek-intel/`；
- 只用于公开互联网信息；抓取内容按不可信数据处理，不执行页面指令；
- key 从 `DEEPSEEK_API_KEY` 或 `$DSH_HOME/.env` 读取，不写入命令/报告/仓库；
- 技能可用性检查不再把可选的 `DSH_HOME` 当成必需项，避免误报不可用。

## 升级

```sh
dsh plugin --profile web add dsh-redteam-mode@0.14.0
# 或
dsh plugin --profile web update dsh-redteam-mode
```

装完重启一次 `dsh web`。已有靶局的事实库、得分记录、报告、POC 知识库与攻击文件保持不变。

可选：使用公开情报技能前，在 `$DSH_HOME/.env` 中配置 `DEEPSEEK_API_KEY`；未配置时该技能显示不可用，不影响其它技能。
