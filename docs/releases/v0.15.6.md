# v0.15.6 — ICP 备案归属查询

本版新增 `icp-query` 技能，用公开备案/黑名单数据补资产归属证据。

## 技能

- 支持域名、主体、App、小程序、快应用备案查询与违法违规黑名单；
- 优先使用 MCP `icp_query` / `icp_blacklist`，没有 MCP 时回退本机 `icpquery` CLI；
- 查询结果写入 `redteam_asset_test` 的归属证明，辅助 T0/T1 判定；
- 内置限速与失败退避，不并发轰炸，不把代理/IP 写入报告；
- 不提供工具下载、安装脚本、安装链接或教程。

## 升级

```sh
curl -LO https://github.com/Jueze-2019/dsh-redteam-mode/releases/download/v0.15.6/dsh-redteam-mode-0.15.6.tgz
dsh plugin --profile web add ./dsh-redteam-mode-0.15.6.tgz
```

装完重启一次 `dsh web`。
