六项需求落地：版本与自动更新、资产发现时间、知识库归类、报告溯源链、多会话隔离，以及**智能体工作逻辑整体重写**。

## 需求实现

**1. 版本显示 + 自动更新**
面板右上角常驻版本号，启动静默比对 npm registry；有新版本点亮按钮 → 弹窗显示当前/最新/安装方式/安装位置/阻塞项 → 一键安装并自动重启 `dsh web`。**检测到有智能体在跑会拦住**，不会打断作业。

**2. 资产测绘加发现时间**
`asset.discovered_at` 首次入库即锁定（重复采集只刷 `last_seen`），列表小字 + 详情行 + 新增「发现时间」视图（按天聚合内/外网）+ 报告附录。老库自动回填。

**3. 知识库归类**
14 类分组（RCE / 反序列化 / 文件上传 / SQL 注入 / 未授权 / 认证绕过 / 弱口令 / SSRF / XXE / 目录穿越 / 信息泄露 / 提权横向 / 隧道 / 其它）+ 建立时间 + 来源靶标 + 发现资产 + 发现角色，可按归类/靶标/资产筛选；老条目按关键词推测归类。

**4. 报告写清「这一分怎么来的」**
每条成果新增「这一步怎么来的」小节：

- **动作步骤**：谁做的（角色）、为什么这么做、**实际命令原文**、回显结果；
- **凭据来源**：账号密码怎么来的（弱口令 / 注入拖库 / 配置泄露 / 凭据复用…）+ 取得方式；
- **隧道**：搭建命令、监听地址、目标侧那一端（`entry_kind`）；
- **WebShell**：连接类型与口令/密钥。

缺步骤、缺命令的条目会被标「复现链不完整」并逐条列出缺口。

**5. 多会话隔离**
靶标绑定按**根会话**记账（`session.header.parentSession` 走到顶），子智能体沿父链继承父会话的靶标；另一个会话 `open` 自己的靶标不会影响它。未绑定的会话**不会被静默塞进别人的库**——会明确报错并要求 `redteam_session_bind`。

**6. 智能体工作逻辑重写（六个角色提示词全部重写）**

- 主会话（指挥）**只做计划 / 派活 / 核对落库 / 汇报，不参与动手**；
- **开工先预检**：`redteam_preflight` 逐个技能查必需环境变量、本机工具与二进制、外部 VPS，缺什么一次性向用户要；补不齐就说明哪部分能力降级并给替代方案；
- **并发硬约束 ≤ 3**：`redteam_agent_slot` 读 `ctx.subagents` 的真实运行数，满了直接拒绝派活（不是靠提示词自觉），默认一个一个派、按顺序推进；
- 六个角色：信息收集（只收资产、收全，重点边缘与未备案资产）→ 资产梳理（**逐条过一遍**、评易打性、全部落库）→ 漏洞发现（先查库去重 → Nday/1day 优先 → 前端接口未授权探测）→ 漏洞利用（先拿服务器权限：冰蝎/哥斯拉马 + 实测用户能连上；再建 suo5 隧道并实测可达内网）→ 内网渗透（走隧道，依次拉起前四个角色，挖出所有内网网段）。

## 新增工具（48 → 53）

```
redteam_preflight        开工前的技能与资源预检
redteam_agent_slot       并发闸门（看名额 / 占位 / 释放）
redteam_session_bind     把一个已有靶标绑到当前会话
redteam_session_info     看当前会话绑的是哪个靶标
redteam_asset_timeline   资产发现时间线（按天聚合 + 最近发现）
```
