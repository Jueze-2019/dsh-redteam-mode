# v0.12.4 — 修复：更新按钮总是提示「当前是开发态安装」，点不动

## 解决了什么问题

在控制台点「检查更新」时，**不管插件是怎么装的**都会显示：

```
现在不能更新：
· 当前是开发态安装（profile 依赖里没有 dsh-redteam-mode，是源码软链/手动挂载的），
  包管理器更新不适用。
```

于是「一键更新并重启」按钮一直是灰的，只能手动升级。原因是安装方式的判断写错了：
把 profile 目录当成文件路径去读，读不到就一律判成开发态。本版修好了这个误判 ——
正常安装（npm / pnpm / tarball）会正确识别为「包安装」，按钮可用。

## 本版改动

- **修正安装方式识别**：正常安装不再被误判成开发态，更新按钮不再被无辜拦下。
- **本地源码安装也不再拦**：如果你是自己 clone 仓库挂上去的，会提示"点击更新会把发布版
  装进 profile，本地源码改动不再生效"；点下去即可切到正式安装，之后一直能用一键更新。
- **更新执行更稳**：首选包管理器不可用时自动改用另一个重试；安装后自动把插件登记进
  profile 的 bundle 列表，避免"装了但重启后没生效"。

## 升级（本版需要手动升一次）

因为**当前版本的更新按钮是坏的**，升级到本版要用一次命令行：

```sh
dsh plugin --profile web add dsh-redteam-mode      # 或 update
```

装完重启一次 `dsh web`。**从本版起，「一键更新」按钮可用了** —— 以后发新版直接在控制台点它，
自动安装并重启，不用再敲命令。

> 如果你是用源码挂载的开发态：`git pull && node packages/redteam-bundle/tools/build.mjs`，
> 再重启 `dsh web`；之后也可以直接点按钮切到发布版。

已有靶局的事实库、得分记录、报告与已配好的技能目录都不受影响，不需要迁移。
