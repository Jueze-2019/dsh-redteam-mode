# v0.12.3 — 修复：DSH 0.1.7 及以上版本里控制台「技能库」打不开

## 解决了什么问题

在 **DSH 0.1.7 及以上**版本中，点开右侧控制台的**技能库**页签会报错、技能列表读不出来：

```
无法解析红队 preset 作用域：ctx.agentPresets.standingKeyFor is not a function
```

原因是 DSH 0.1.7 改了 preset 作用域的接口，而插件还在调旧接口。本版完成适配，
升级并重启 `dsh web` 后技能库恢复正常。资产库、控制台其它页签、工具与模式入口不受影响。

> 建议连同 0.12.1 一起理解：0.12.1 修的是"新会话里选不到「红队模式」"，
> 本版修的是同一批 DSH 改动导致的"技能库打不开"。两个都升级才算完整适配 0.1.7+。

## 本版改动

- **技能库适配 DSH 0.1.7 起的 preset 接口变化**，能正常列出「红队会话实际能用到的技能」
  并读取技能正文；对旧版 DSH 保持兼容，行为不变。
- 保留原有的降级提示：万一将来接口再次变化，报错里会直接列出当前可用的方法名，便于定位。

## 兼容性

| 你的 DSH | 升级到本版后 |
| --- | --- |
| 0.1.7 及以上 | 技能库正常（本版修复的目标） |
| 0.1.6 及更低 | 行为不变，照常可用 |

## 升级

```sh
dsh plugin --profile web add dsh-redteam-mode      # 或 update
```

装完**重启一次 `dsh web`**（host 侧代码在启动时加载），然后打开右侧控制台的技能库确认。

已有靶局的事实库、得分记录、报告与已配好的技能目录都不受影响，不需要迁移。
