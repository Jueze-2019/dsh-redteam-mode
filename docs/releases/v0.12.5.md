# v0.12.5 — 控制台改版：页签精简、并发可配、技能不可用直接给修复方法

## 一、页签精简：12 → 9 个，相关的东西放在一起

| 原来的页签 | 现在在哪 |
| --- | --- |
| 当前测试 | **资产测绘**页左侧，与「全部 C 段 / 外网资产 / 内网资产」同级（紫色「测」标记） |
| 智能体提示词 | **智能体**页（并发配置、角色速览、提示词编辑同一页） |
| 攻击文件 | **漏洞战果**页的子页签 |

旧的书签/链接（`#testing` / `#attackfiles` / `#prompts`）不会失效，会自动落到对应的合并后页面。

## 二、并发数量可以自己配了（默认 3）

控制台「智能体」页新增**并发数量**配置：填数字、保存，**立即生效**，不用再改环境变量重启 `dsh web`
（存 `$DSH_HOME/redteam/settings.json`，范围 1–10；闸门每次派活现读，面板会显示当前值来自哪里）。

> ⚠️ **调大不等于更快**：同一个模型 API Key 的并发/速率上限是共享的，同时派太多会互相挤占，
> 表现为排队等待、超时、返回被截断甚至限流报错 —— 反而让测试结果不稳定。
> 建议从 2–3 开始，只有确认 Key 的额度足够、任务之间确实互不依赖时才调大。

## 三、技能库：不可用不再只说"哪里不行"，而是直接告诉你"怎么修"

原来只列"缺口"，现在每条不可用都写清 **不可用原因 + 修复方法**，例如：

- 缺工具 → 直接给装法（`bash $DSH_HOME/redteam/setup.sh --yes`；系统工具给对应 apt 包名；
  不在安装脚本清单里的给获取方式），并按缺失路径逐条列出缺的是哪个工具、干什么用的；
- 缺 `FOFA_KEY` → 给取 key 的入口与一条自测命令；
- VPS 还是占位符 → 给三种填法（`REDTEAM_VPS_HOST` / 环境变量 / 直接编辑技能文件）。

覆盖面：**54 个工具**的安装/补配方法 + **23 份技能**各自的额外修复步骤。

## 四、漏洞和攻击文件对上了

「漏洞战果」新增**攻击文件**子页签；每条漏洞的详情里新增**关联攻击文件** ——
直接列出这条漏洞留下了哪些脚本 / 马 / EXP（类型、名称、说明、落盘路径）。
子页签顶部会提示还有多少文件没挂到漏洞上，方便补齐对应关系。

## 五、顺手修的

- 从「当前测试」切回资产列表时，点外网/内网分组或某个 C 段现在能正常切回去了。
- 「当前测试」的标记改用紫色，不再和外网资产（橙色）混在一起。

## 升级

```sh
dsh plugin --profile web add dsh-redteam-mode      # 或 update
```

装完重启一次 `dsh web`。**已经有 0.12.4 的直接在控制台点「一键更新并重启」也行。**

已有靶局的事实库、得分记录、报告与已配好的技能目录都不受影响，不需要迁移。
