# v0.15.4 — 更新检查改走 GitHub Release

本版起，检查更新与一键更新不再依赖 npm registry 或 npm 账号：直接从 GitHub Release 读取最新版本并安装对应 tarball。npm/pnpm 只负责解包本地下载的附件，不再访问 npm registry。

## 更新

- 检查更新改为读取 GitHub Release 的 latest tag；
- 一键更新下载对应 `.tgz` Release 附件并安装；
- GitHub API 不可用时如实报错，不回退到 npm；
- 已安装旧版本的用户需要手动安装一次本版 tarball，之后即可使用 GitHub 更新通道。

## 升级

```sh
curl -LO https://github.com/Jueze-2019/dsh-redteam-mode/releases/download/v0.15.4/dsh-redteam-mode-0.15.4.tgz
dsh plugin --profile web add ./dsh-redteam-mode-0.15.4.tgz
```

装完重启一次 `dsh web`。
