# v0.13.0 — 证据截图 + 报告改成「复现手册」

> 主题：**得分成果从"写清楚了"变成"看得见、能照着跑"**。一条成果现在同时有三样东西：
> 一张图（证据）、一个可执行的复现入口（报文或命令）、一句明确的成功判定标准。

## 一、证据截图：得分点上看图，报告里贴图

- **控制台「得分目标」页**：展开任一得分点即可看到证据截图，点图全屏放大；命中行会标注这一条有几张图。
- **同一个得分点最多展示 3 张代表图**（批量成果如终端权限一次几十台，逐台贴图没有信息量，
  取代表即可），超出部分只报数，不铺开。
- **报告里嵌入证据截图**：每条得分点下图，图注写明类型、时间与原始来源；
  附带导出脚本会把 `shots/` 一起拷到输出目录并用**相对路径**引用，整个目录拷走或打包都不会碎图。
- **图片落盘、库只存元数据**：图片存 `<靶标目录>/shots/`，事实库里只记文件名、尺寸、字节与 sha256 ——
  事实库始终可拷可备份，不会因为贴了图就膨胀到打不开。
- **新增三个工具**：`redteam_shot_add`（本机路径或 base64 登记，可按得分点 / 命中 / 目标关联）、
  `redteam_shot_list`、`redteam_shot_delete`。
- **现场截图与"生成的证据摘录"严格分开**：`kind=screenshot` 是现场截的图，`kind=card` 是由当日记录
  生成的证据摘录卡；面板给不同标记，报告里分别标注，代表图**优先取现场截图**。
  角色提示词也补了这条纪律：拿到成果顺手留一张图，现场截的才写 `screenshot`。

## 二、报告重写成「复现手册」，结构固定

```
0 摘要与对账   总分 / 计分项 / 复现入口分类 / 证据截图 / 得分点占用 / 记录与计分对账 / 复现索引
1 复现前置条件 通道与启动命令、凭据、Burp/Yakit 与 proxychains 接入方式、工具能力边界
2 攻击链       按阶段 ①→⑤、阶段内按取得时间，逐条标注前置
3 逐条明细     复现入口 → 证据截图 → 目标台账 → 动作记录 → 证据索引
4 得分点说明   判定标准与要附的材料集中讲一次
5 附录         涉及资产（含发现时间）、未计分的重复记录、档位校正记录
```

- **复现入口三态**：可直接粘贴进 Burp / Yakit 的原始报文；可直接跑的命令行；该得分点的标准复现动作。
  真实命令永远优先于得分点自带的通用模板，不会再出现"模板冒充本步实际命令"。
- **重建报文如实标注**：当日请求没有逐字节留存时，报告写明"重建报文"，不会说成现场抓包。
- **一次批量动作合并成一条 + 目标台账表**：一次动作打下几十台，只写一条正文加逐台清单，
  报告不再被同一段内容刷屏。
- **按链路顺序编排并标注前置**：每条写出"先做过哪条成果"；前置关系只从凭据来源与证据文本推导，
  推不出来就不写。
- **得分点说明集中一次**：判定标准与材料要求收进第 4 节，正文不再逐条重复同一段话。
- **附录可对账**：资产与发现时间、未计分的重复记录、档位校正记录都列清楚。

## 三、可复现性与准确性的修复

- 非 HTTP 目标（数据库、SMB、隧道等）不再合成无意义的 HTTP 报文。
- 由真实报文推导命令行时保留查询串与鉴权头 —— 否则合出来的 curl 少了 `Authorization`，跑起来是 401。
- 逐条只列**本条真正用到**的凭据，不再把同资产上无关的接口 token 一并挂上。
- 面板与报告措辞统一为「复现步骤」「复现材料」，去掉内部记账口径的提示文案。
- 界面文案与报告小节名统一，报告页与导出 markdown 读到的结构一致。

## 四、新增脚本

```sh
node scripts/export-engagement-report.mjs --out ~/交付/<靶标>
```

一条命令导出可移动的交付目录：报告 markdown + `shots/` 证据图（相对路径引用）。
控制台「报告」页的「下载 .md」仍然可用（图片走绝对路径，适合本机查看）。

## 质量

零依赖回归测试 **15 个文件 / 595 条断言**全过（新增证据截图专项测试，覆盖"每个得分点最多 3 张"
"现场截图与生成卡片分标""图片不进库""面板与报告都能渲染出图"），`build --check` 无漂移。

## 升级

```sh
dsh plugin --profile web add dsh-redteam-mode      # 或 update
```

装完重启一次 `dsh web`。已有靶标的事实库、得分记录、报告与技能配置不受影响，不需要迁移 ——
新的证据截图表在打开靶标时自动创建。
