# v0.15.1 — 专项技能随包修正

> 修正 v0.15.0 的打包范围：新增专项技能随 npm 包分发。

## 打包

- 新增的 10 个专项技能随 npm 包分发：AD、云 / K8s、网络设备、API 数据、OOB、供应链、C2、OPSEC、AI/Agent、移动端；
- 9 个攻击链技能仍不随包，保持独立附件方式。

## 兼容性

- 功能与 v0.15.0 相同，仅修正 npm 包技能清单。
- npm 包技能数：29 个（v0.15.0 为 19 个）。

## 升级

```sh
dsh plugin --profile web add dsh-redteam-mode@0.15.1
# 或
dsh plugin --profile web update dsh-redteam-mode
```

装完重启一次 `dsh web`。
