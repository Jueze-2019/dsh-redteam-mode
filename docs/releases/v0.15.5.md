# v0.15.5 — 内网收集与利用拆分

本版把内网信息收集从内网渗透中拆出，新增 `internal-recon` 执行角色，并收紧边界突破、对象存储权限与测试数据纪律。

## 智能体

- 执行角色从 5 个增加到 6 个：新增 `internal-recon`；
- `internal-recon` 只做内网收集、资产落库、可达性与候选评估，不利用、不记分、不建隧道；
- `internal` 消费内网地图，按 P0 凭据复用/横向提权 → P1 数据 → P2 新 RCE 执行；
- 主会话按“信息收集 → 资产梳理 → 漏洞发现 → 漏洞利用 → 内网信息收集 → 内网渗透”派活。

## 记分与安全

- 逻辑/强隔离/供应链边界必须绑定真实 `tunnel_id`；SSRF、一次性代理请求不算突破隔离；
- `file-storage` 必须绑定有效 `access_id`；匿名读写、匿名列举不算存储权限；
- 禁止向目标业务写入“XX红队测试”、队伍标识、假身份信息、XSS/弹窗/留言等无法获得权限的测试数据。

## 升级

