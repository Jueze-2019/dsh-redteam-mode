# v0.12.0 — 记分口径补全，npm 版改为「编排 + 事实库」

> 主题：**说不清归属的 Web 站点不再漏记**，同时把 npm 包与"工具链"分开 ——
> npm 版只装编排与事实库，需要工具与攻击链技能的用户按需取用。

## 一、Web 应用系统权限加了兜底归类

`web-app` 这一类现在明确包含三种：**邮箱系统**、**办公自动化与业务生产系统**、
以及**其他 Web 应用系统（兜底）**——凡是凭据实测能登录的 HTTP/HTTPS 站点，
只要归不进集权 / 大数据 / 云平台 / 物联网平台 / 安全设备这些更具体的类别，
一律记这一条，管理员 100 分 / 普通 50 分，上限 2000 分不变。

对使用者意味着：凭据清单里只写了 `host:port`、没有系统名或业务归属的后台、管理端、
运营平台、自研业务系统，登录成功就能记分，不用再纠结"算不算邮箱/OA"。

## 二、登录之后先归类再记分

角色的动作顺序里加了一步：**先用真实浏览器登录一次，登录成功后再判断这个系统归哪一类**
（邮箱/OA/业务生产 → `web-app`；堡垒机/域控/SSO/终端管理后台 → `central-system`；
大数据 → `bigdata-system`；云平台 → `cloud-platform`；物联网管控平台 → `iot-platform`；
安全设备 → `secdev`；套不进任何一类的 → `web-app` 兜底）。
记分时 `target` 写实际登录 URL（带端口），证据里写清站点 + 账号 + 管理员/普通档位。

## 三、得分点数量口径统一

面板、工具说明与提示词里对得分点数量的表述统一为《突破入侵类得分规则（合并版）》的
**8 类 25 项**，与实际内置得分点一致（此前几处写成 22 项 / 20 项）。规则本身与分值
没有变化，已有得分记录不受影响。

## 四、npm 版不再随包分发工具链（本版最大的变化）

从本版起，npm 包 `dsh-redteam-mode` **只包含编排与事实库**：六个角色、预检、
SQLite 事实库、得分规则、报告、右侧控制台，以及 **14 个侦察/检测向技能**
（资产测绘、被动收集、端口/服务/指纹识别、目录与模板扫描等）。

**不再随包分发**（有意为之，不是漏打包）：

- 环境安装脚本 `redteam-setup.sh` —— 它会在本机自动下载一批安全工具二进制；本插件
  现在**不会替用户下载或安装任何安全工具**；
- 9 个攻击链技能：`credential-attack`、`webshell-toolkit`、`vps-reverse-shell`、
  `shell-handler`、`unauth-exploit`、`lateral-movement`、`suo5-tunnel`、`chisel-tunnel`、
  `frp-tunnel`。

需要这些能力的用户，从本仓库 **Release 附件** `dsh-redteam-mode-<版本>-toolkit.tar.gz`
获取（内含安装脚本与那 9 个技能，附带使用说明），**由自己执行**；也可以只用
`redteam-setup` 技能逐项手动配置。

对已有用户的影响：升级到本版后，那 9 个技能不再随包出现；本机已装好的工具二进制、
已有靶标库与得分记录**都不受影响**。若你依赖"一键铺环境"，请取工具箱附件。

## 升级

```sh
dsh plugin --profile web add dsh-redteam-mode     # 或 update
```

升级后重启 `dsh web` 即可。已有靶局的事实库、得分记录、报告都不用迁移。
