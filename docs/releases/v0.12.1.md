# v0.12.1 — 修复：DSH 0.1.7 及以上版本里选不到「红队模式」

## 解决了什么问题

在 **DSH 0.1.7 及以上**版本中，新建会话的模式列表里看不到「红队模式」，因此没法用
"发一个靶标单位名称就拉起红队智能体"这个入口。插件的其余部分（资产库、右侧控制台、
工具、技能）一直是正常的。

本版修好了它：升级并重启 `dsh web` 后，「红队模式」重新出现在模式列表里。

## 本版改动

- **「红队模式」重新可以在新会话中选择** —— 适配 DSH 0.1.7 起的模式加载方式。
- **插件自带技能改为自动定位**：随包的 14 个侦察/检测向技能，无论插件装在哪
  （npm/pnpm 安装目录、重装后的新目录、本地软链开发）都能被正确加载；
  你自己放在 `$DSH_HOME/skills` 下的技能，优先级仍然高于包内同名技能。
- **修掉一处与新版 DSH 不兼容的委派配置**：如果不改，负责子智能体委派的那一行会激活失败。

## 兼容性

| 你的 DSH | 升级到本版后 |
| --- | --- |
| 0.1.7 及以上 | 模式列表里能看到「红队模式」（本版修复的目标） |
| 0.1.6 及更低 | 功能不变，照常可用；日后升级 DSH 也不需要再换插件版本 |

## 升级

```sh
dsh plugin --profile web add dsh-redteam-mode      # 或 update
```

装完**重启一次 `dsh web`**，新会话里即可选择「红队模式」。

已有靶局的事实库、得分记录、报告，以及你已经配好的技能目录**都不受影响**，不需要迁移。
