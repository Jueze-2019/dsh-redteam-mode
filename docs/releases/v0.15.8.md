# v0.15.8 — 智能体持续作战与单资产深挖

本版把内网主机和互联网资产都改成“覆盖度 + 下一动作队列”驱动，避免打一个点就收口、批量扫完就交。

## 内网主机

- 新增 host coverage / next action：文件、凭据、提权、Web、DB、横向逐项跟踪；
- 未完成项会持续返回；收口前必须全部 done / blocked / not_applicable；
- 新增 `host-post-exploit` 技能，覆盖 Linux/Windows 主机后渗透。

## 漏洞发现

- 新增 asset coverage：surface / web / auth / cve / app 五项；
- 主会话按单个资产派 `vuln-scan`，批量扫描只作为候选生成；
- `exploit` 接同一资产，发现不足时回退补查；
- 新增 `asset-deep-scan` 技能和 `redteam_asset_next` 队列。

## 升级

```sh
curl -LO https://github.com/Jueze-2019/dsh-redteam-mode/releases/download/v0.15.8/dsh-redteam-mode-0.15.8.tgz
dsh plugin --profile web add ./dsh-redteam-mode-0.15.8.tgz
```

装完重启一次 `dsh web`。
