# v0.14.3 — 模板化报告与作战规划增强

> 本版把交付报告统一为“资产归属证明 → 得分汇总 → 得分点复现”，并给红队智能体补上作战规划与专项资产路径。

## 报告

- 资产归属证明拆分为互联网资产和内网入口资产，附归属类型、证明强度、证据与截图；
- 得分汇总按互联网 / 边界 / 内网 / 靶标四个阶段组织，新增 2.4 靶标权限；
- 得分点复现按互联网资产、边界隧道、内网网段、靶标权限组织；
- 内网按第一层边界隧道 → 双网卡 / 可达网段 → 未归属网段排序；
- 得分汇总表按报告配置显示明文凭据；
- 页面与下载 Markdown 共用同一份报告数据，下载文件名保留靶标中文名；
- 补齐复现命令、Yakit / HTTP 报文、响应摘要、攻击文件路径、证据文件路径和复现缺口。

## 智能体

- 新增 `campaign-planning`：目标、范围、攻击假设、时间盒、噪声预算、停止条件、独立复核与清理；
- 新增 `specialist-paths`：AD / 身份、边界设备、云 / K8s、IoT / OT、文件备份、AI / Agent 的专项路径选择；
- 主会话与执行角色接入作战规划、专项路径和复核要求；
- 随包技能 18 个，总计 27 个。

## 升级

```sh
dsh plugin --profile web add dsh-redteam-mode@0.14.3
# 或
dsh plugin --profile web update dsh-redteam-mode
```

装完重启一次 `dsh web`。已有靶局的事实库、得分记录、报告、POC 知识库与攻击文件保持不变。
