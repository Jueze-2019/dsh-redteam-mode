# v0.15.0 — 得分阶段简化、留痕减负与资产准入

> 本版移除独立“靶标系统”阶段和“攻击链”页面，合并证据写入，并在派活前加入资产分级，减少无效攻击和漏报。

## 得分与报告

- 得分阶段统一为四段：信息收集 → 互联网资产权限 → 边界突破 → 内网资产权限；靶标系统按资产归属记入互联网或内网，不再单独计分。
- 旧“靶标”阶段得分与步骤自动迁移；历史数据保留。
- 报告改为三段（互联网 / 边界 / 内网），删除原 2.4、3.4 靶标段，复现结构不变。

## 页面与留痕

- 移除“成果 → 攻击链”页面，保留 9 个页面；漏洞战果、得分目标不变。
- `redteam_vuln_add` 带 `request`/`response` 自动保存 HTTP 证据；`redteam_score_hit` 带 `command`/`result` 自动生成动作记录。
- 移除 `redteam_chain_add` / `redteam_chain`；正常成果落库从 4 次调用降为 2 次。

## 工具

- 批量落库：`redteam_batch`（资产 / 评估 / 漏洞）。
- 范围校验：`redteam_scope_check`；`redteam_batch` 会跳过 scope 外条目。
- 隧道实测：`redteam_session_check` 支持 `probe_targets`，新增 `redteam_pivot_probe`。
- 数据证明：`redteam_data_proof`（字段 / 条数 / 样本 / 来源，≥1 万条标记达标）。
- 清理台账：`redteam_cleanup`（登记 / 查询 / 标记）。
- 工具总数 59。

## 智能体

- P0 先进内网 RCE，P1 再拿 ≥1 万条三要素数据。
- 资产准入 T0–T3：只打直接归属 / 强相关资产；旁站、同 C 段等弱相关资产只作线索，强相关攻击线路穷尽并经用户确认后才评估。
- 技能分类、外部能力回退、提示词精简。

## 升级

```sh
dsh plugin --profile web add dsh-redteam-mode@0.15.0
# 或
dsh plugin --profile web update dsh-redteam-mode
```

装完重启一次 `dsh web`。

## 兼容性

- 0.15.0 移除独立“靶标”阶段；旧库会自动迁移，已有资产、漏洞、得分、凭据、隧道、报告与 POC 知识库保留。
