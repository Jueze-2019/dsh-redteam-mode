# v0.14.1 — Windows 桌面端标题栏避让

> 修复 DeepSeek Harness Windows 桌面端上，RedTeam 控制台与系统窗口按钮重叠的问题。

## 更新内容

- RedTeam 控制台和全屏预览不再从窗口最顶部开始，而是按 DSH 桌面标题栏高度向下避让；
- 面板不再覆盖 Windows 的“最小化 / 最大化 / 关闭”按钮，头部按钮也不会落入原生拖拽区；
- 普通浏览器/Web 端没有桌面标题栏变量时保持原有布局，不产生额外空隙；
- 其余功能与 v0.14.0 相同。

## 升级

```sh
dsh plugin --profile web add dsh-redteam-mode@0.14.1
# 或
dsh plugin --profile web update dsh-redteam-mode
```

装完重启一次 `dsh web`。已有靶局的事实库、得分记录、报告、POC 知识库与攻击文件保持不变。
