# v0.12.2 — 内部整理，无功能变更

本版只做仓库与包内内容的整理，**功能与 v0.12.1 完全一致**，没有新增、修改或移除任何能力。
已经用 0.12.1 的话，**不需要**为了功能升级。

## 本版改动

- 清理代码与配置里的历史注释，只保留"这条约束是什么、为什么必须这样"的说明。
- 统一仓库内文档的口径（安装、版本对应关系）。
- 敏感值检查（发布前自检的一部分）改为从环境变量读取，仓库与包里不再保留任何密钥素材。

## 升级

```sh
dsh plugin --profile web add dsh-redteam-mode      # 或 update
```

如果你当前是 0.12.1，可以留在 0.12.1，功能上没有任何差别。
